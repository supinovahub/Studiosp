# Handoff — UI e UX

## Direção aprovada

- Interface em português do Brasil.
- Paleta terrosa, preto como cor de ação principal e remoção do roxo dominante.
- Preservar contratos funcionais enquanto as telas são redesenhadas.
- Responsividade móvel e estados de carregamento/erro fazem parte do aceite.

- A repaginação terrosa foi publicada.

## Pontos de atenção

- Não alterar nomes de rotas, contratos de API ou estados operacionais apenas por conveniência visual.
- Evitar modais que crescem além do viewport ou comprimem a página atrás.
- Formulários longos devem ser agrupados por intenção, com hierarquia e feedback de salvamento.
- Datas relativas, auditoria e mensagens de erro precisam estar em português.
- Homologação visual é manual pelo usuário; o agente não usa controle do Chrome.
